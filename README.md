# HarvestNav · 출하 내비게이션

**출하 물량과 시장별 가격·비용을 바꾸며 단일 출하와 분산 출하의 예상 순수취액을 비교하는 의사결정 지원 도구입니다.**

KAMIS 지역별 조사 가격으로 시장 흐름을 살펴보고, 직접 입력한 경매가격·상품화율·수수료·운송비를 바탕으로 출하 시나리오를 비교합니다. 배추 예시를 중심으로 계산 근거와 물량 흐름을 함께 확인할 수 있습니다.

## 서비스 접속

[HarvestNav 웹사이트 열기](https://kamis-harvestnav.onrender.com/)

무료 호스팅의 휴면 상태에서는 첫 접속 시 기동에 약 1분이 걸릴 수 있습니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 출하 전략 비교 | 현재 배분, 단일 시장 출하, 5% 격자 배분 후보의 예상 순수취액 비교 |
| 비용·물량 조건 설정 | 상품화율, 시장별 단가·수수료·처리비, 차량 용량·운송비, 최소 물량·수용량 반영 |
| 스트레스 비교 | 경매가격 하락과 운송비 상승을 가정한 결과 비교 |
| KAMIS 가격 조회 | 지역·품종·등급·기간별 배추 조사 가격, kg 환산값, 관측 변화율·조회 근거 확인 |
| 전국 시장 지도 | 전국 8개 시장의 물량 흐름 시연과 선택한 2개 시장의 출하 전략 비교 |
| 계산 근거·자료 저장 | 항목별 비용표, 배분 후보 그래프·재생 로그, 입력·결과 JSON 및 선택 가격표 CSV 저장 |

AI 설명은 출하조건과 계산 결과의 해석을 돕는 선택적 연동 기능입니다. 수취액 계산은 Python 엔진이 수행하며, AI 연동의 모델·인증 설정과 데이터 전송 범위는 [배포 안내](docs/deployment.md)에 설명합니다.

## 사용 흐름

1. **출하조건 입력** — 물량과 상품화율, 비교할 2개 시장의 가격·비용·물량 제약을 설정합니다.
2. **전략 비교** — 현재 배분과 단일·분산 출하 후보의 수취액, 비용, 배분 물량을 비교합니다.
3. **조건 변화 확인** — 가격 하락률과 운송비 상승률을 바꾸며 스트레스 결과를 살펴봅니다.
4. **조사 가격 참고** — KAMIS에서 같은 지역·품종·등급의 가격 흐름과 조사일·단위를 확인합니다.
5. **근거 저장** — 계산 내역과 입력·결과, 조회 근거 및 선택 가격표를 저장합니다.

지도에서는 전국 8개 시장의 예시 물량 흐름을 재생하거나 2개 시장을 선택해 전략을 비교할 수 있습니다. 8개 시장 동시 시연의 배분 비율과 2개 시장 수취액 계산은 별도로 관리합니다.

## KAMIS 자료와 시뮬레이션 입력

| 구분 | 자료와 역할 |
|---|---|
| KAMIS 조사 가격 | 공공데이터포털의 지역별 배추 중도매인 판매가격. 조사일·원가격·조사단위·kg 환산 근거와 함께 표시 |
| 경매가격·출하비용 | 이용자가 입력하는 시뮬레이션 가정. 기본값과 시장별 프리셋은 합성 예시 |
| 지도 물량·이동 | 배분 조건을 표현하는 시각화. 시장·산지 지점은 예시 좌표이며 차량은 직선 경로로 이동 |

KAMIS 중도매인 판매가격은 개별 경매시장 낙찰가격과 다른 지표이므로 경매 단가에 자동 대입하지 않습니다. 조사 가격의 변화율을 스트레스 조건에 적용하는 경우에도 해당 비율을 경매가격에 적용한다는 가정으로 구분합니다.

가격 조회는 공공데이터포털 `perRegion/price`를 사용합니다. 조회 시각과 조사 기준일을 구분하고, 원자료의 명시 중량으로 kg 가격을 환산합니다. 중량을 확인할 수 없는 행은 추정하지 않으며, 조회 실패를 합성 가격으로 대체하지 않습니다. 자세한 처리 기준은 [자료 출처와 KAMIS 연동 범위](docs/data-sources.md)를 참고하세요.

## 계산 예시

[배추 합성 시나리오](examples/cabbage.synthetic.json)의 총 물량 5,000kg, 상품화율 95%와 동일한 시장별 가격·비용 조건을 사용한 결과입니다.

| 항목 | 서울 가락 60% · 구리 40% | 구리 100% |
|---|---:|---:|
| 판매대금 | 7,315,000원 | 7,600,000원 |
| 총비용 | 1,042,625원 | 890,000원 |
| 예상 순수취액 | **6,272,375원** | **6,710,000원** |
| 현재 배분 대비 차액 | 기준 | +437,625원 |

계산의 기본 관계는 **예상 순수취액 = 판매대금 − 수수료·처리비·시장사용료·운송비·기타 비용**입니다. 상품화율은 매출에 적용하고, 차량 수는 배분 물량과 차량 용량에 따라 올림 계산합니다. 계산은 Python `Decimal`로 수행합니다.

위 차액은 같은 합성 입력에서 배분만 바꾼 계산 결과입니다. 실제 농가 수익 증가나 시장 추천 성과를 의미하지 않습니다. 상세 공식과 반올림 기준은 [계산 공식과 예제](docs/calculation.md)에 정리했습니다.

## 로컬 실행

### 실행 환경

- Python 3.12 또는 3.13
- Node.js 22.12 이상 및 npm
- 실제 가격 조회용 공공데이터포털 serviceKey

인증키 없이도 합성 시나리오 계산과 지도 시연을 사용할 수 있습니다. 아래 명령은 Windows PowerShell에서 저장소 루트를 현재 폴더로 연 상태를 기준으로 합니다.

### 설치와 빌드

Python 3.13을 사용하는 예시입니다. 기존 가상환경은 재사용합니다.

```powershell
if (-not (Test-Path -LiteralPath '.\.venv\Scripts\python.exe')) {
    py -3.13 -m venv .venv
    if ($LASTEXITCODE -ne 0) { throw '가상환경 생성 실패' }
}
& '.\.venv\Scripts\python.exe' -m pip install -r requirements.txt
if ($LASTEXITCODE -ne 0) { throw 'Python 의존성 설치 실패' }
npm.cmd --prefix frontend ci
if ($LASTEXITCODE -ne 0) { throw '프론트엔드 의존성 설치 실패' }
npm.cmd --prefix frontend run build
if ($LASTEXITCODE -ne 0) { throw '프론트엔드 빌드 실패' }
```

Python 3.12로 새 가상환경을 만들 때는 생성 명령에서 `py -3.12`를 사용합니다. 다른 개발 환경과 개발 서버 실행 방법은 [로컬 실행과 개발](docs/local-development.md)을 참고하세요.

### 가격 조회 인증

실제 가격을 조회하려면 프로젝트 루트의 [.env.example](.env.example)을 참고해 `.env`를 만들고 공공데이터포털 일반 인증키의 **Decoding 값**을 저장합니다. KAMIS 자체 API의 인증 ID/KEY와 구분합니다.

실제 `.env`는 Git에서 제외하며 인증키는 서버에서만 읽습니다. 프론트엔드 코드나 `VITE_` 변수에 넣지 않습니다. 설정 절차와 환경변수 우선순위는 [로컬 인증키 관리](docs/local-env.md)에 설명합니다.

### 서버 실행

```powershell
& '.\.venv\Scripts\python.exe' -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --no-access-log
```

- 웹 화면: <http://127.0.0.1:8000>
- API 문서: <http://127.0.0.1:8000/docs>
- 서버 종료: `Ctrl+C`

프론트엔드 빌드 후 FastAPI가 화면과 API를 같은 주소에서 제공합니다.

### 테스트와 빌드 확인

```powershell
& '.\.venv\Scripts\python.exe' -m pytest -q
if ($LASTEXITCODE -ne 0) { throw '테스트 실패' }
npm.cmd --prefix frontend run build
if ($LASTEXITCODE -ne 0) { throw '프론트엔드 빌드 실패' }
```

API 자동 시험은 임시 설정과 합성·모의 응답을 사용합니다. 실제 가격 API 조회와 구분합니다.

## 검증 범위

[검증 기록](docs/validation.md)의 2026-10-28 기준 결과입니다.

| 구분 | 확인 범위 |
|---|---|

| 실제 조사 자료 | 서울·여름(고랭지)·상품 배추 14개 조사일의 원가격과 명시된 10kg 중량에 따른 환산 대조 |

| 화면·지도 | 합성 계산 응답과 기존 조회 자료로 입력·배분·재생·저장 흐름 확인 |
| AI 요청·응답 | 모의 제공자 응답을 이용한 요청 제한·오류 처리·구조화 응답 및 표시 시험 |

실제 이용자 시험, 농업 현장 사용성, 실현 수익·시간 절감 효과는 위 검증 범위에 포함하지 않습니다.

## 결과 해석

- 예상 순수취액은 입력한 비용 항목을 차감한 값입니다. 생산비·세금·손실 비용이 모두 반영된 순이익과 구분합니다.
- 배분 후보는 설정한 격자와 물량 제약 안에서 비교합니다. 격자 밖의 전역 최적 배분이나 미래 가격·수익을 보장하지 않습니다.
- 전국 지도는 예시 물량 흐름을 표현합니다. 실제 도로 경로·GPS·도착시간·배송 완료율을 나타내지 않습니다.
- 출발지와 예정일은 기록용이며 거리·운임을 자동 산정하지 않습니다.

## 자료 및 시각 자산 출처

가격 자료는 한국농수산식품유통공사(aT) KAMIS의 [지역별 품목별 도·소매 가격정보](https://www.data.go.kr/data/15156062/openapi.do)를 사용합니다. 지도 지형은 Natural Earth, 웹 글꼴은 IBM Plex Sans KR·IBM Plex Mono, UI 아이콘은 Lucide입니다.

자료·글꼴·아이콘·소프트웨어의 출처와 이용조건은 [외부 패키지와 시각 자산](docs/third-party.md)에 정리했습니다. 가격 자료의 처리·공개 범위는 [자료 출처](docs/data-sources.md)를 참고하세요.
