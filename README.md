# 출하 내비게이션 HarvestNav

출하 담당자가 물량·시장별 경매가격·비용 조건을 바꾸며 단일 시장 출하와 분산 출하의 예상 순수취액을 비교하는 의사결정 지원 도구입니다. KAMIS 조사 도매가격은 시장 흐름의 참고 정보로 분리합니다.

## 현재 구현

- 배추 합성 시나리오: 물량·상품화율·시장별 단가·요율·운송비 변경
- 입력표·전략 비교표·배분표·검증 현황을 모은 관리자 장표형 UI
- 연녹색 바탕·흰 카드·포레스트 버튼, 다크 결과 요약/계산 로그, 앰버 스트레스 강조
- 지도·상세 조건·KAMIS·계산 근거까지 통일한 반응형 화면
- 계산 완료 후 배분 후보 로그 자동 재생·일시정지·처음부터·1×/3×/8× 제어
- 배분 비율별 기본·스트레스 수취액 그래프
- 시장별 배분 비율에 연동한 차량 이동 애니메이션·일시정지
- Natural Earth 지형 위 전국 8곳 동시 배분 시연·1×/3×/8× 재생·2개 시장 선택과 수취액 비교 ([범위와 예시 데이터](docs/national-map.md))
- 접속·지도 진입 즉시 차량 자동 재생, 일시정지·재생 제어, 0 물량 시 차량 제거 (모션 축소는 장식 효과에 적용)
- 차량 용량·차량 수·최소 출하량·수용량을 반영한 비용 계산
- 5% 배분 격자에서 단일·분산 출하 비교, 현재 배분과의 가상 차액
- 가격 하락·운송비 상승을 함께 적용하는 가정된 스트레스 비교
- 계산 내역 확인, 입력과 결과 JSON 저장
- 서버 측 KAMIS 호출 어댑터, 조사일·가격·응답 단위 검증, 시계열별 분석 구조
- KAMIS 조회·분석 근거 JSON, 선택 가격표 CSV 저장과 실제 비교 날짜 간격 표시
- 조사 자료를 참고한 스트레스 조건 비교와 해당 근거를 포함한 시나리오 저장
- 프로젝트 루트 `.env` 인증키 자동 읽기, 기존 가상환경 재사용

**검증 상태(2026-10-28):** 계산·API·설정 테스트 102개와 React/TypeScript 프로덕션 빌드를 통과했습니다. 공공데이터포털 `perRegion/price`의 실제 서울·여름(고랭지)·상품 배추 자료 14개 조사일을 내보내 원가격과 kg 환산을 대조했습니다. 별도 검사 코드의 공식 API 3일 재조회 일치는 개발자의 Windows 실행 출력으로 확인했습니다. 이는 같은 제공기관·같은 API의 대조이며 독립기관 검증이 아닙니다. 실제 이용자 시험과 농가 수익 효과 검증은 미실시입니다. AI 응답 처리는 모의 제공자 응답을 사용하는 자동 시험으로 확인했습니다. 상세 범위는 [검증 결과](docs/validation.md)에 구분합니다.

## 빠른 실행

Python 3.13 가상환경과 프론트엔드 빌드가 이미 준비되어 있다면 프로젝트 루트에서 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --no-access-log
```

화면은 `http://127.0.0.1:8000`입니다. 실제 가격을 조회하려면 VS Code에서 프로젝트 루트 `.env`를 만들고 `DATA_GO_KR_SERVICE_KEY`를 한 번 저장합니다. [처음 설치와 빌드](docs/local-development.md), [VS Code 인증 설정](docs/local-env.md)을 참고하세요. 인증이 없어도 합성 계산과 지도는 사용할 수 있습니다.

## 설계

React + TypeScript + Vite 프론트엔드와 Python FastAPI 백엔드로 구성합니다. 계산은 Decimal을 사용하며, 브라우저는 계산 API를 호출합니다. 공공데이터포털 serviceKey는 서버 환경변수 또는 Git에서 제외한 프로젝트 루트 `.env`에서 읽습니다. 프론트엔드 빌드 후에는 FastAPI가 화면과 API를 같은 주소에서 제공합니다.

공공 가격 조회와 예시 출하조건을 분리하여 구현했으며, 가격 예측 모델은 연결하지 않았습니다. 계산 결과는 이용자가 입력한 출하조건에 대한 시뮬레이션입니다.

AI 설명 기능은 출하조건과 계산 결과를 바탕으로 결과 해석을 돕는 선택적 연동 기능입니다. 서버의 모델·인증 설정을 통해 연결하며, 수취액 계산은 Python 엔진이 수행합니다. 연동 구조는 [API 계약](docs/api.md), 설정과 데이터 전송 범위는 [배포 안내](docs/deployment.md)를 참고하세요.

## 결과와 한계

합성 예시에서 5,000kg을 서울 가락 60%, 구리 40%로 배분하면 판매대금 7,315,000원, 비용 1,042,625원, 예상 순수취액 6,272,375원입니다. 같은 입력에서 구리 100%의 계산 결과는 6,710,000원입니다. 이 차이는 실제 농가 수익 증가나 시장 추천의 실증 결과가 아닙니다.

KAMIS의 중도매인 판매가격과 경매 낙찰가격은 다른 지표입니다. 조사값을 경매 단가로 치환하지 않습니다. 생산비·세금·손실 비용이 모두 포함된 순이익을 산출하지 않으며, 격자 밖의 전역 최적 배분·다음 날 가격·수익을 보장하지 않습니다. 출발지와 예정일은 기록용이며 거리·운임·예측값을 자동으로 생성하지 않습니다.

## 자료 및 시각 자산 출처

KAMIS 조사 가격, Natural Earth 지도, IBM Plex 글꼴, Lucide 아이콘 및 SVG 시각화의 원출처와 이용조건은 [외부 패키지와 시각 자산](docs/third-party.md)에 정리했습니다. 공공데이터 처리 범위는 [자료 출처와 KAMIS 연동 범위](docs/data-sources.md)를 참고하세요. 별도로 제작한 보고서·아키텍처 구성도의 추가 이미지·기업 로고·글꼴은 해당 자료별로 이용조건을 확인해야 합니다.
