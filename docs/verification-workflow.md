# 실제 KAMIS 활용과 사용자 확인 절차

2026-10-28 기준 절차와 완료 범위를 구분합니다. 현재 인증은 공공데이터포털 serviceKey이며 [로컬 설정](local-env.md)을 사용합니다.

## 확보한 근거

서울·여름(고랭지)·상품 배추의 실제 14개 조사일 JSON, 원가격/10kg 환산 대조, 별도 공식 API 3일 재조회 일치 실행 출력, 개발자 Windows 화면 2장을 확보했습니다. 상세 조건과 한계는 [자료 출처](data-sources.md), [검증 결과](validation.md)를 따릅니다. 이 작업을 다시 수행해야 하는 미완료 항목으로 취급하지 않습니다.

조회 시각과 조사일, 원가격과 원/kg, 7일 변화율 0%와 전체 관측기간 약 −1.89%를 구별합니다. 가을03 자료와 여름02 자료를 합치지 않습니다.

## 이후 조회를 대조할 때

1. 지역·품목·품종·등급·조사기간을 고정해 조회합니다. 조회 실패와 자료 없음을 구별합니다.
2. 조회 근거 JSON과 가격표 CSV를 보존합니다. 원가격·원단위·단위크기·명시 중량·환산 방법을 확인합니다.
3. 같은 조건의 원응답 또는 공식 화면과 대조한 날짜·값·시각·결과를 기록합니다. 중량을 추정하거나 다른 시계열로 대체하지 않습니다.
4. 비교에 사용한 조사일과 실제 날짜 간격을 기록합니다. 비조사일 보간은 하지 않습니다.
5. 인증키·전체 요청 URL·개인정보를 증빙에 넣지 않습니다.

## 일반 이용자 사용성 시험 — 아직 미실시

개발에 참여하지 않은 일반 대학생·지인 2~3명이 화면에서 다음을 수행할 수 있는지 확인합니다. 농업인 현장 검증이 아닌 탐색적 사용성 시험입니다.

- 가격 출처·조사일·단위를 찾아 설명하기
- 합성 입력을 변경하고 단가와 비용을 포함한 결과를 구별하기
- 조건·결과 JSON을 저장하고 실제 가격과 합성 가정을 구분하기

과제별로 혼자 완료·도움받아 완료·미완료, 실제 수행시간, 도움 내용, 관찰된 혼란을 익명 기록합니다. 참가자용 질문에 정답을 넣지 않고 진행자만 판정표를 봅니다. 입력 설명에 들인 시간과 수행시간을 구분하고, 연결 장애 시 자료 읽기 대체 과제였는지 표시합니다.

화면·음성 녹화 없이 메모만으로 진행할 수 있습니다. 목적과 익명 기록 사용을 설명하고 동의를 받습니다. 참가자의 이름·연락처·학교 등 식별 정보는 수집하지 않습니다. 중도 중단도 허용합니다. 개발자의 직접 조작은 참가자 결과로 세지 않습니다.

소수의 비전문가 결과로 출하 의사결정의 현장 적합성·실제 수익·시간 절감률을 입증하지 않습니다. 일반 이용자의 이해·조작에서 발견한 문제와 UI 개선 근거로 사용합니다.

## 최종 보고서와 시연

실제 조회 조건·원천 대조, 합성 비용 비교, 일반 이용자 시험 결과(시행한 경우), 남은 한계를 분리합니다. 시연 재생은 계산된 배분 후보를 순서대로 표시하는 기능이며 실시간 경매나 실제 차량 추적이 아닙니다.

아직 남은 작업은 실제 참가자 기록, 최종 UI 반영과 필요한 캡처 교체, 공식 양식·분량·서식 확인, 최종 제출 파일 검토입니다. 실제 수익 증가·가격 예측 성능·시간 절감 효과를 검증하기 전에는 성과 수치로 적지 않습니다.
