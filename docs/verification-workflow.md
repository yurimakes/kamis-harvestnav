# 실제 KAMIS 활용과 사용자 확인 절차

2026-10-28 기준 검증 방법과 완료 범위를 구분합니다. 인증은 공공데이터포털 serviceKey를 사용하며 [로컬 설정](local-env.md)에 따라 서버 측에서 관리합니다.

## 실제 가격 자료 대조 범위

서울·여름(고랭지)·상품 배추의 서로 다른 14개 조사일에 대해 원가격과 명시된 10kg 중량에 따른 kg 환산 결과를 대조했습니다. 별도 공식 API 3일 재조회 일치는 개발자 Windows 실행 출력으로 확인했습니다. 해당 검증의 조건과 한계는 [자료 출처](data-sources.md), [검증 결과](validation.md)에 설명합니다.

조회 시각과 조사일, 원가격과 원/kg, 7일 변화율 0%와 전체 관측기간 약 −1.89%를 구별합니다. 품종이 다른 가을03 자료와 여름02 자료를 합치지 않습니다. 같은 API의 재조회는 독립기관 검증에 해당하지 않습니다.

## 가격 자료 재현·확인 절차

1. 지역·품목·품종·등급·조사기간을 고정해 조회합니다. 조회 실패와 자료 없음을 구별합니다.
2. 조회 근거 JSON과 가격표 CSV를 보존합니다. 원가격·원단위·단위크기·명시 중량·환산 방법을 확인합니다.
3. 같은 조건의 원응답 또는 공식 화면과 대조한 날짜·값·시각·결과를 기록합니다. 중량을 추정하거나 다른 시계열로 대체하지 않습니다.
4. 비교에 사용한 조사일과 실제 날짜 간격을 기록합니다. 비조사일 보간은 하지 않습니다.
5. 인증키·전체 요청 URL·개인정보를 증빙에 넣지 않습니다.

## 사용성 시험 방법 — 미실시

개발에 참여하지 않은 일반 이용자 2~3명이 화면에서 다음 작업을 수행할 수 있는지 평가하는 방법을 정의했습니다. 이는 농업인 현장 검증이 아닌 탐색적 사용성 시험이며, 2026-10-28 기준 실제 시험은 실시하지 않았습니다.

- 가격 출처·조사일·단위를 찾아 설명하기
- 합성 입력을 변경하고 단가와 비용을 포함한 결과를 구별하기
- 조건·결과 JSON을 저장하고 실제 가격과 합성 가정을 구분하기

실시할 경우 과제별 독립 완료·도움받아 완료·미완료, 수행시간, 도움 내용, 혼란 지점을 익명 기록합니다. 진행자 개입 시간과 수행시간을 구분하고, 연결 장애 시 대체 과제 여부를 표시합니다. 녹화가 아닌 익명 관찰 기록을 사용할 수 있으며, 참가자의 동의를 받고 이름·연락처·학교 등 식별 정보를 수집하지 않습니다. 개발자의 직접 조작은 참가자 시험 결과로 계산하지 않습니다.

소수의 비전문가 사용성 시험만으로 출하 의사결정의 현장 적합성·실제 수익·시간 절감률을 입증하지 않습니다.

## 결과 해석과 시연 범위

실제 KAMIS 조사자료의 조회·단위 환산, 합성 입력으로 계산한 비용 비교, 별도로 실시하는 사용성 시험의 결과는 구분해 보고합니다. 시연 재생은 계산된 배분 후보와 가상 차량 이동을 표시하는 기능이며 실시간 경매나 실제 차량 추적이 아닙니다.

검증되지 않은 실제 수익 증가·가격 예측 성능·시간 절감 효과를 실증 성과로 표현하지 않습니다.
