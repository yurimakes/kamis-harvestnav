# 예상 순수취액 계산

총 물량은 kg, 경매가격은 원/kg입니다. 시장별 배분비율의 합은 정확히 100%여야 합니다. 상품화율은 매출에만 적용합니다.

| 항목 | 계산 |
|---|---|
| 시장 배분 물량 | 총 물량 × 시장 비율 / 100 |
| 판매 가능 물량 | 배분 물량 × 상품화율 / 100 |
| 판매대금 | 판매 가능 물량 × 해당 시장 경매가격 |
| 위탁수수료 | 판매대금 × 위탁수수료율 / 100 |
| 하역·처리비 | 판매대금 × 하역비율 / 100 + 배분 물량 × 물량당 처리비 |
| 시장사용료 | 판매대금 × 시장사용료율 / 100 |
| 차량 수 | 올림(배분 물량 / 차량 용량) |
| 운송비 | 차량 수 × 차량 1대 비용 + 배분 물량 × 변동 운송비 |
| 시장 수취액 | 판매대금 − 위탁수수료 − 하역·처리비 − 시장사용료 − 운송비 |
| 전체 순수취액 | 시장 수취액의 합 − 기타 비용 |

미사용 시장의 비용과 차량 수는 0입니다. 물량이 0이면 기타 비용도 0입니다. 비용이 매출보다 크면 음수 수취액을 그대로 반환합니다. 시장을 사용하면 최소 물량과 수용량 상한을 만족해야 합니다. 기타 비용은 전체 시나리오에서 한 번만 차감합니다.

## 재현 가능한 합성 예시

`examples/cabbage.synthetic.json`의 가격·요율·운임은 기능 검증용 가정입니다. 시장의 현재 요율이나 실제 계약 운임이 아닙니다.

| 조건/결과 | 서울 가락 | 구리 | 합계 |
|---|---:|---:|---:|
| 출하량 kg | 3,000 | 2,000 | 5,000 |
| 단가 원/kg | 1,500 | 1,600 | - |
| 상품화율 | 95% | 95% | - |
| 판매대금 원 | 4,275,000 | 3,040,000 | 7,315,000 |
| 매출 기준 비용률 | 7.5% | 7.5% | - |
| 매출 기준 비용 원 | 320,625 | 228,000 | 548,625 |
| 운송비 원 | 210,000 | 284,000 | 494,000 |
| 순수취액 원 | 3,744,375 | 2,528,000 | 6,272,375 |

구리 100%는 판매대금 7,600,000원 − 매출 비용 570,000원 − 운송비 320,000원 = 6,710,000원입니다. 현재 배분과의 가상 차액은 437,625원입니다. 모든 시장의 가격 -10%, 운송비 +10%를 함께 적용한 현재 배분의 수취액은 5,546,337.50원입니다.

## 탐색과 정밀도

5% 격자의 모든 배분 조합에 현재 배분과 각 단일 시장 배분을 추가하고 중복을 제거합니다. 최소 물량·수용량 조건을 위반하는 후보는 제외합니다. 기본 UI는 2개 시장, API는 최대 3개 시장을 받습니다. UI에서는 총 물량을 정수 kg로 입력하고, 배분 결과는 소수 kg일 수 있습니다.

계산은 Decimal로 수행하고 순위는 반올림 전 순수취액으로 정합니다. API의 금액은 소수 둘째 자리 반올림, 화면은 원 단위 반올림입니다. 화면에서 반올림한 개별 금액 합계와 합계 표시값이 미세하게 다를 수 있습니다.

스트레스 비교는 확률·예측구간이 아닌 조건 변경 계산입니다. 가격 하락 비율은 경매 단가에, 운송비 상승 비율은 고정·변동 운송비에 적용하며 기타 비용은 유지합니다.
