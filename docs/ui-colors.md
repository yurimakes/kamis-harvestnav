# UI 배색

장표 레이아웃의 정보 구분을 유지하면서 바탕은 쿨민트 계열로 구성합니다.

| 영역 | 색상 |
|---|---|
| 바탕 | 쿨민트 `#eff5f4` |
| 입력·물량 배분 머리글 | 민트 `#d9eae6` |
| 재생 제어 머리글 | 살구 `#efcfaa` |
| 전략 비교·검증 머리글 | 옐로 `#f3e7a8` |
| 시장 입력·차트 보조 머리글 | 블루 `#d7e5f3` |
| 선택 후보 머리글 | 핑크 `#efdce7` |
| 전략 계산 재생 로그 바탕 | 다크 네이비 `#132733` |
| 로그 수취액 | 골드 `#f2c66f` |

색만으로 상태를 구분하지 않고 각 영역의 제목·값·자료 상태를 함께 표시합니다. 로그는 현재 입력으로 계산한 후보의 재생이며 실제 경매 수신이 아닙니다. 지도 및 기존 계산 기능은 유지합니다.
