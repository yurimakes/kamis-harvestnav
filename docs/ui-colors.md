# UI 배색과 화면 구성

HarvestNav의 화면은 연녹색 바탕·흰 카드·짙은 결과 영역으로 정보 위계를 구분합니다. 주요 작업 버튼에는 포레스트 그린을, 가격 하락·운송비 상승 등 스트레스 가정에는 앰버 색상을 사용합니다.

| 영역 | 색상 |
|---|---|
| 바탕 / 카드 / 머리글 | `#EEF3EC` / `#FFFFFF` / `#F6F9F5` |
| 본문 / 보조 본문 / 설명 | `#13261C` / `#4B5E52` / `#5A6E62` |
| 주요 버튼 / 최대값 / 서울 가락 | `#1E6B43` |
| 선택 강조 / 구리 | `#E5F3E9` / `#7CC79A` |
| 결과 요약·재생 로그·AI 진입 | `#0D2419` / 강조 `#A8E063` |
| 스트레스·주의 | `#C66A0E` / 바탕 `#FDF1E2` / 글자 `#8A4505` |
| 다크 영역의 스트레스 글자 | `#F3B86E` |

장표는 기본 입력·중앙 결과·후보/로그의 3열, 지도는 지형+오른쪽 배분 제어, 상세 조건은 입력+흐름과 결과, KAMIS는 조회+상태/자료와 안내, 계산 근거는 수식+상세 비용표입니다. 좁은 화면에서는 열을 접고 상세 비용표만 내부에서 가로 스크롤합니다. AI 패널은 큰 화면에서 본문을 줄여 나란히 열며 작은 화면에서는 전체 너비로 열립니다.

IBM Plex Sans KR와 IBM Plex Mono를 사용하고 시스템 글꼴 대체를 지정했습니다. 본문·표의 숫자는 탭 간격과 오른쪽 정렬로 비교합니다. 색만으로 구분하지 않고 제목·상태·단위를 함께 표시합니다. 재생은 계산 후보와 가상 물량 흐름이며 실제 가격 갱신·배송 추적이 아닙니다.

지도·글꼴·UI 아이콘 등 외부 시각 자산의 출처와 이용조건은 [외부 패키지와 시각 자산](third-party.md)에 정리했습니다.
