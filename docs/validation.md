- 0 물량·음수 수취액·기타 비용·수수료·처리비·스트레스 계산

- 전체 페이지 수신과 한도, 인증키 Encoding 처리, 캐시, 원문 오류·비밀값 비노출

## 실제 KAMIS 자료 대조

개발자 Windows에서 공공데이터포털 `perRegion/price`를 조회해 저장한 JSON을 확인했습니다. 서울1101·배추211·여름(고랭지)02·상품04·중도매02, 요청기간 2026-10-06~27, 실제 관측은 10-06~26의 **14개 조사일**입니다.

수신·환산·관측 모두 14건이며 내보내기 품질 필드의 결측·중복·중량 미확인·기간 밖 행은 0입니다. 모든 관측의 원가격 ÷ 명시 10kg을 Decimal로 대조했습니다. 최근 가격 2,080원/kg, 최근 7일 내 관측 5건 평균 2,080원/kg, 10-19 대비 10-26의 7일 변화율 0%입니다. 첫 2,120원/kg 대비 전체 관측기간 변화율 약 −1.89%와 구분합니다.

앱 정규화 함수를 사용하지 않는 별도 검사 코드로 공식 API를 재조회한 결과는 다음과 같습니다. 근거는 개발자가 제공한 Windows 실행 출력이며, 저장된 재조회 JSON 본문을 별도로 확인한 것은 아닙니다.
