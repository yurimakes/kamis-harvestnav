# 기능 검증 결과

2026-10-27, Linux Python 3.12.14 / Node.js 24.22.1에서 검증했습니다. 실제 농업인 사용성 시험이나 실현 수익 검증이 아닙니다.

## 계산과 API

프로젝트 루트의 `python -m pytest -q`에서 **40개 테스트가 통과**했습니다.

- 합성 예제의 손계산 대조: 예상 순수취액 6,272,375원
- 단일 시장 전략과 가상 차액 437,625원 대조
- 미사용 시장의 차량비 0, 차량 용량 초과 시 추가 차량비
- 가격이 같을 때 분산 출하의 추가 고정비로 인한 불리함
- 최소 물량·수용량 제약, 3개 시장 격자, 현재 배분 후보 포함
- 0 물량·음수 수취액·기타 비용·물량당 처리비·스트레스 계산
- 고정 난수 70가지 조건에서 배분량 보존·매출/비용/수취액 정합성
- 음수·범위 초과·소수 총 물량·비율 합 오류·비정상 숫자 거부
- 합성 KAMIS 응답의 날짜·결측·중복·시장별 시계열 분리
- 단위 미확인·상충 가격·인증 없음·호출 실패 처리
- 오류 응답에 임의 입력값을 재출력하지 않는지 확인

테스트 실행 중 Starlette TestClient와 HTTPX 조합의 사용 중단 예고 경고 1개가 있었습니다. 테스트 실패는 없었지만 향후 해당 테스트 클라이언트 의존성 갱신 시 대응이 필요합니다.

## 빌드와 브라우저

`frontend`에서 `npm run build`의 TypeScript 검사와 Vite 7.3.7 프로덕션 빌드를 통과했습니다. Chromium 153에서 실제 FastAPI 서버와 빌드 화면을 연결해 다음 동작을 확인했습니다.

| 동작 | 관측 결과 |
|---|---|
| 최초 합성 시나리오 | 6,272,375원 표시 |
| 물량 6,000kg 변경 | 7,614,850원으로 재계산 |
| 6,000kg 가락 100% | 차량 2대 비용을 포함해 7,488,750원 |
| 6,000kg 격자 최대 전략 적용 | 구리 100%, 7,844,000원 |
| 물량 -1kg 입력 | 계산 불가 표시, 결과 숨김 |
| 물량 0kg 입력 | 0원 |
| 가격 하락률 수정 | 입력값 유지 및 재계산 |
| 조건·결과 저장 | JSON에 합성 출처·입력·동일 계산값 포함 |

| 위 조작 흐름 | JavaScript 실행 오류 없음 |

브라우저 검증 환경의 한국어 글꼴을 보완해 화면을 확인했습니다. 앱은 별도 외부 폰트를 포함하지 않으며 Windows에서는 운영체제 글꼴을 사용합니다.

## 아직 수행하지 않은 검증

실제 KAMIS 인증 API 호출·현재 코드북·응답 구조·kg 단위 대조, LightGBM 재실행, KAMIS 특징 기여도 실험, 농업인 현장 사용성 시험, Windows PowerShell 실행, 외부 배포 환경 검증은 수행하지 않았습니다. 현재 결과는 합성 계산과 로컬 실행 흐름의 검증 근거입니다.


## 가로형 대시보드와 지도 UI 갱신 검증

2026-10-27 로컬에서 수정본의 TypeScript/Vite 빌드와 계산/API 테스트 40개를 다시 통과했습니다. Chromium에서 차량 SVG 위치가 시간에 따라 바뀌는지, 일시정지 후 고정되는지, 지도 확대/전국 보기, 0 물량에서 차량이 사라지고 물량 증가 시 다시 나타나는지를 확인했습니다. 이전 계산·전략 적용·오류·JSON 내보내기·KAMIS 미연결 처리도 회귀 확인했습니다. 390px 화면에서 가로 넘침이 없었습니다.

움직임은 입력 연동 시뮬레이션입니다. 실제 차량 GPS·도로 경로·도착 시간·실시간 가격 수집을 검증한 결과가 아닙니다. 지도 좌표는 예시 지점이며 실제 농가 위치를 포함하지 않습니다. 사용자 Windows PC에 수정본을 적용하고 실행하는 검증은 별도입니다.


## 장표형 UI 갱신 검증

첨부 레퍼런스를 참고해 기본 화면을 좌측 입력/중앙 전략 비교/우측 후보와 로그의 3열 장표로 변경했습니다. 새 UI의 TypeScript·Vite 빌드와 기존 계산/API 40개 테스트가 통과했습니다. Chromium에서 후보 재생·속도 변경·일시정지·물량 변경·최대 전략 적용·음수/0 물량·스트레스 프리셋·JSON 내보내기·KAMIS 미연결 상태를 확인했습니다. 390px 화면에 가로 넘침과 JavaScript 실행 오류가 없었습니다.

재생은 계산한 배분 후보를 순서대로 표시합니다. 그래프 가로축은 서울 가락 배분비율이며 미래 시간축이 아닙니다. 임의의 실제 경매값·모델 MAE·적중률·성능 개선율을 만들지 않습니다. Windows PC 적용과 현장 검증은 별도입니다.


## 쿨민트 확정 후 KAMIS 근거 기능 검증

2026-10-27 프로젝트 루트에서 계산·API 테스트 **47개 통과**, 경고 1개입니다. 추가 검증은 공백/예시 인증 거부, 공식 오류 코드 900·200 및 미확인 코드 분류, 원문 오류 메시지 미노출, 실제 달력 일수 비교 간격입니다. 기존 40개 검증도 통과했습니다.

프로덕션 빌드 통과. Chromium에서 기존 장표 10개 조작 항목과 새 기능을 확인했습니다. KAMIS 자료 있음 경로는 **합성 HTTP 응답을 주입**한 시험이며 실제 API 조회 근거가 아닙니다. 확인 항목은 선택 시계열·코드·관측 건수와 비교 일수, JSON 저장, UTF-8 BOM을 포함한 CSV 저장, CSV 수식 시작 문자 무력화, 참고 자료를 보존한 시나리오 저장과 가정 변경 구분, 기록 해제, 390px 화면 가로 넘침 없음입니다.

쿨민트 섹션 배색과 다크 네이비 로그를 실제 빌드 화면에서 확인했습니다. 실제 KAMIS 인증 조회·현재 기간별 명세와 코드표 대조·원천값 대조, 수정한 Windows 스크립트 실행은 여전히 미완료입니다. 제출 보고서 초안은 실제 이용 기록을 반영하기 전 상태입니다.

추가 확인: 합성 하락 시계열에서 관측 −12.5%가 명시적인 가정 12.5%로 연결되고 저장 근거의 `basis`가 구분됩니다. 전체 후보가 음수인 경우에도 그래프가 축 범위 안에 표시되는지 확인했습니다. 지도 GeoJSON이 Git 제외 규칙에 가려지지 않도록 공개용 지도 소스만 명시적으로 포함했습니다.
