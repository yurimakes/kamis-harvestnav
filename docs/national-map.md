# 전국 시장 지도 시연

지도에서 서울 가락·구리·춘천·대전 오정·전주·광주 각화·대구 북부·부산 엄궁 등 8개 시장 권역 중 2곳을 골라 비교합니다. 수도권, 충청·영남, 호남·영남 예시를 전환하고 총량·배분율을 바꾸면 연결선·차량·물량이 갱신됩니다. 선택한 시장은 기존 계산 API에도 전달되며 메인·상세 조건·근거 표의 이름과 결과가 함께 바뀝니다. 동시에 8개 시장을 최적 배분하는 기능은 아닙니다.

`frontend/src/markets.ts`의 단가·요율·차량비·용량·변동 운송비는 기능 시연용 예시입니다. 실제 해당 시장의 가격·운임·수용량·계약 조건을 조사해 산정하지 않았습니다. 시장 변경 시 새 후보의 예시 입력값을 불러오며, 사용자는 상세 조건에서 자신의 값으로 바꿉니다. 실제 KAMIS 지역 조사값은 기존 가격 탭에서 별도로 조회합니다. 지역 조사 가격을 선택 시장의 경매가격으로 치환하지 않습니다.

시장·산지 좌표는 권역을 참고한 예시로, 시설 입구의 검증된 좌표가 아닙니다. 도로 경로·거리·도착 시간·GPS를 수신하지 않으며 선은 직선입니다. 산지 좌표는 지도 내부의 시각화 상태이며 수취액이나 운임을 자동 변경하지 않습니다. 지도 탭을 다시 열면 산지는 초기화됩니다. 디지털 트윈 표현은 입력에 연동한 시연 범위를 뜻하며 실시간 현장 동기화·물류 최적화를 검증한 시스템은 아닙니다.

시장 명칭 참고: [한국농촌경제연구원 농업전망 자료](https://aglook.krei.re.kr/upload/event/hwp/time3/3%EB%B6%808%EB%B6%84%EA%B3%BC_%EA%B3%BC%EC%B1%84.pdf), [농림축산식품부 공영도매시장 현황](https://www.mafra.go.kr/bbs/mafra/65/251652/download.do). 이 출처가 앱의 예시 가격·운임을 제공한 것은 아닙니다.

## 검증

기존 Python 시험 102개와 TypeScript/Vite 빌드를 통과했습니다. 브라우저에서는 실제 엔진이 산출한 예시 응답으로 권역 전환, 후보 선택, 메인 결과 연동, 중복 시장 선택 방지, 0kg 차량 제거, 일시정지를 확인했습니다. 예시 광주60%·부산40%·5,000kg의 수취액은 6,203,425원입니다. 이는 실제 출하 수익이나 신규 시장의 실조회 결과가 아닙니다.
