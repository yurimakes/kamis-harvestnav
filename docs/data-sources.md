# 자료 출처와 KAMIS 연동 범위

## 가격의 역할과 현재 연결

현재 화면의 가격 조회는 공공데이터포털 [지역별 품목별 도·소매 가격정보](https://www.data.go.kr/data/15156062/openapi.do)의 `https://apis.data.go.kr/B552845/perRegion/price`를 사용합니다. 명세·코드와 처리 한도는 [포털 연동](portal-integration.md)에 설명합니다.

KAMIS 중도매인 판매가격은 지역 조사 가격이며 개별 경매시장 낙찰가격과 다릅니다. 합성 시뮬레이션의 경매 단가로 자동 대입하지 않습니다. 과거 조사 변화율을 경매가에도 동일하게 적용하는 경우에도 명시적인 스트레스 가정이며, 가격 전이 관계·미래 가격·수익을 예측한 결과가 아닙니다.

`backend/app/services/portal.py`가 현재 조회를 담당합니다. `kamis.py`의 자체 API 어댑터는 이전 구현 및 회귀 비교용이며 현재 가격 경로가 아닙니다. 공통 통계 함수는 현재 어댑터에서도 사용합니다. 인증은 공공데이터포털 serviceKey 한 개이며 자체 API ID/KEY를 요구하지 않습니다.

## 자료 처리

- 요청의 구분·품목·품종·등급·지역 코드를 응답과 대조합니다.
- 원 조사가격을 단위와 `unit_sz`로 확인한 kg 중량으로 나눕니다. `kg(그물망 3포기)`와 양수 중량 10은 10kg 조사단위로 처리합니다. 포기 수에서 중량을 추정하지 않습니다.
- 원가격·원단위·단위크기·kg 중량·환산 방법을 JSON/CSV에 보존합니다. 기준이 확정되지 않은 환산가격 필드를 자동 사용하지 않습니다.
- 결측·중복·중량 미확인·기간 밖 행을 구분합니다. 같은 조사일에 가격 또는 원자료가 상충하면 중단합니다.
- 서로 다른 지역·품종·등급 자료를 임의 평균하지 않으며 비조사일을 보간하지 않습니다.
- 최근 7일 내 관측 평균과 7일 이전 가장 가까운 과거 관측 대비 변화율을 구분합니다. 실제 비교일과 간격을 표시합니다.
- 조회 시각(KST)과 조사 기준일을 구분합니다. 5분 캐시를 사용해도 원 조회 시각을 유지하며, 실패 시 합성 가격으로 대체하지 않습니다.

## 실제 확인한 범위 — 2026-10-28

개발자 Windows에서 내보낸 서울1101·배추211·여름(고랭지)02·상품04·중도매02 자료를 확인했습니다. 요청기간은 2026-10-06~27이며 유효 관측은 10-06~26의 서로 다른 14개 조사일입니다. 원가격과 10kg 중량으로 각 관측의 환산을 대조했습니다.

| 비교 | 확인값 |
|---|---|
| 첫 관측 10-06 | 21,200원 / 10kg = 2,120원/kg |
| 최근 관측 10-26 | 20,800원 / 10kg = 2,080원/kg |
| 10-19 → 10-26 | 7일 변화율 0% |
| 10-06 → 10-26 | 전체 관측기간 변화율 약 −1.89% |
| 최근 7일 관측 평균 | 5개 관측, 2,080원/kg |

별도 검사 코드로 공식 API를 재조회한 10-06·19·26의 원가격 일치는 개발자 제공 실행 출력으로 확인했습니다. 같은 제공기관·동일 API의 별도 코드 대조입니다. 독립기관 검증이나 공식 웹페이지 대조로 표현하지 않습니다. 저장된 재조회 JSON 본문은 별도로 읽지 않았습니다.

서울·가을03 자료 1건의 900원/kg은 품종이 달라 위 시계열과 합치지 않습니다. 이 검증은 해당 조건·기간에 한정되며 모든 지역·품종의 정확성을 증명하지 않습니다.

## 외부 자료와 공개 범위

공식 정보는 [KAMIS](https://www.kamis.or.kr)와 위 포털 상세 페이지를 참고합니다. 다른 API의 데이터·이용조건은 개별적으로 확인해야 합니다. 조회 근거와 원천 대조의 세부 범위는 [검증 결과](validation.md)에 기록합니다.

저장소에는 기존 비공개 거래 CSV, KADX 원본, 모델 가중치, 전자송품장 원본, 실제 인증키, 원첨부 명세서나 개인 기록을 포함하지 않습니다. 테스트 응답은 직접 만든 합성 fixture이며 실측 근거와 구분합니다. 원자료·개인정보가 포함될 수 있는 내보내기 파일은 검토 후 별도 증빙으로 선택합니다.
