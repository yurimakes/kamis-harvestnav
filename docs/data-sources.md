# 자료 출처와 KAMIS 연동 범위

> 현재 기본 조회는 공공데이터포털 `perRegion/price`입니다. 인증·단위·실행은 [현재 연동 가이드](portal-integration.md)를 우선 적용하세요. 아래 자체 API 설명은 이전 구현 기록이며 serviceKey와 혼용하지 않습니다.

## 가격의 역할

KAMIS의 중도매인 판매가격은 가격 흐름을 참고하는 조사 가격입니다. 개별 시장 경매 낙찰가격과 같지 않습니다. 시뮬레이션의 경매 단가는 합성 입력이며 KAMIS 조사 가격을 직접 대입하지 않습니다.

KAMIS 조회 성공 후 가격 변화 신호를 참고해 가격 하락 가정을 검토하는 흐름을 제공합니다. -10% 등 하락률은 사용자가 조절하는 가정이며, KAMIS로 학습하거나 보정한 예측값이 아닙니다.

## 공식 출처

- [KAMIS](https://www.kamis.or.kr)
- [KAMIS 자체 Open API 기간별 가격 안내](https://www.kamis.or.kr/customer/reference/openapi_list.do?action=detail&boardno=2)
- [공공데이터포털 일별 도·소매 가격정보](https://www.data.go.kr/data/15156057/openapi.do)
- [공공데이터포털 가격 추이 정보](https://www.data.go.kr/data/15156069/openapi.do)

공공데이터포털 일별 API 안내는 2026-10-27 확인 시 조사일자·품목·품종·등급·지역·시장·단위·조사 가격·kg 환산 가격을 제공한다고 설명하며, 무료·이용허락범위 제한 없음으로 표시합니다. 개별 데이터 및 다른 제공기관의 조건은 별도로 확인해야 합니다.

## 구현된 어댑터와 미검증 범위

현재 코드는 **KAMIS 자체 Open API**의 `periodProductList` 방식에 대한 서버 측 어댑터입니다. 공공데이터포털 신규 API와 인증·응답 구조가 다릅니다. 포털의 serviceKey를 이 어댑터에 대신 넣지 않습니다.

현재 실행에서는 실제 인증 조회에 성공한 결과가 없습니다. 공식 상세 명세 페이지도 정상적으로 열리지 않아 현재 응답 스키마·코드북을 최종 대조하지 못했습니다. 따라서 KAMIS 실제 활용을 증명하는 앱으로 완성되었다고 주장할 수 없습니다.

어댑터는 품목 코드 211(배추), 구분 02(도매), kg 환산 요청을 사용합니다. 품종·등급 코드와 응답의 품목명·단위를 실제 응답으로 재확인해야 합니다. 응답의 단위가 없거나 `kg`/`1kg`로 확인되지 않으면 자동 환산하지 않고 조회 오류를 반환합니다. 실응답이 단위를 별도로 제공하는 구조라면 공식 명세에 맞춰 검증기를 보완해야 합니다.

## 정규화 규칙

- 정상 오류 코드·일별 가격 목록 확인
- `yyyy` + `regday` 또는 ISO 날짜를 조사일로 변환
- 요청 기간 밖 레코드 제외, 평균·합계 행 제외
- 결측 가격 `-` 등을 제외하고 건수 기록, 0·음수·비정상 가격 차단
- 같은 시장·품종·지역별로 시계열 분리, 다른 시장을 임의 평균하지 않음
- 같은 조사일·시장·가격의 중복은 제거, 가격이 상충하면 중단
- 최근 7일 내 관측값의 평균 계산, 비조사일 보간 없음
- 7일 이전 가장 가까운 과거 관측값을 비교일과 함께 표시
- 표본이 2개 미만이면 최근 구간 변동계수 미제공

응답에 조사 기준일, 조회 시각(KST), 요청 코드, 단위, 결측·중복 건수, 공식 출처를 포함합니다. 5분간 같은 조건의 정상 조회를 재사용하며 조회 시각을 새로 만들지 않습니다. 실패 시 합성 값이나 이전 자료로 자동 교체하지 않습니다.

## 포함하지 않은 자료

기존 프로젝트의 비공개 거래 CSV, KADX 원본, 모델 가중치, 전자송품장 원본을 포함하지 않았습니다. 테스트 내 KAMIS 형태의 응답은 코드 검증용으로 직접 만든 합성 fixture이며 실측 증거가 아닙니다.


## 조회 근거 저장과 대조

2026-10-27 재확인 시 KAMIS 일별 부류별 API 안내(boardno=1)는 열렸고 kg 환산 요청 옵션과 인증 ID/KEY, 오류 코드 000·001·200·900을 확인했습니다. 그러나 현재 사용하는 기간별 API 상세(boardno=2)와 코드표 다운로드는 계속 시간 초과였으므로 기간별 응답 구조를 최종 확인한 것으로 간주하지 않습니다. 일별 API와 기간별 API의 파라미터 이름을 혼용하지 않습니다.

실제 조회 후 JSON/CSV를 저장하고 공식 화면에서 같은 지역·품종·등급·단위·조사일의 원천값을 최소 3일 대조해야 합니다. 조회 근거의 결측·중복은 전체 요청 기준, 관측 건수는 선택 시계열 기준입니다. 과거 관측 비교 간격이 7일보다 길 수 있어 실제 비교 간격을 함께 저장합니다. 가격 관측의 공백은 비조사일과 자료 누락을 현재 단계에서 구별할 수 없습니다.

참고 자료를 선택해 스트레스 비교를 실행하면 해당 자료의 사본과 사용자가 검토한 가정을 시나리오 저장에 포함합니다. 이는 의사결정 절차 기록이며 수익 개선이나 KAMIS의 인과 효과를 증명하지 않습니다.

관측 변화율이 음수이면 **관측 하락률을 같은 하락 가정으로 비교**하는 추가 버튼을 제공합니다. 조사 가격의 실제 과거 하락률을 경매가에도 동일하게 가정하는 스트레스이며, 두 가격 사이의 전이 관계나 미래 경매 하락률을 검증한 값은 아닙니다. 저장 자료의 `assumption.basis`는 이 경우 `observed_change_scenario`, 별도 −10% 검토는 `manual_review`로 구분합니다.
